# Rule-ROM 生态系统

Decima-8 是计算 substrate。其他域负责个性作者、验证与应用动作。

| 域 | 责任 |
| --- | --- |
| [Rule-ROM](https://rulerom.com/zh/) | 项目与发布边界的注册表 |
| [Philo](https://philo.rulerom.com/zh/) | 架构师、个性、事件记忆与类比边界 |
| [Bakery](https://bakery.rulerom.com/zh/) | `.d8p` 构建、分析与可复现性 |
| [Whaler](https://whaler.rulerom.com/) | 第一个 Decima-8 应用系列 |
| [C-SAFE](https://c-safe.rulerom.com/zh/) | 验证与审计 |
| [PKI](https://pki.rulerom.com/zh/) | 签名与 artifact 来源 |

架构师定义个性，runtime 执行个性，应用 director 解释事件。这些角色被有意分离。
