# DECIMA-8 — детерминированная нейроморфная машина

> Восемь линий общего входа. Тысячи локальных интеграторов. Событие вместо непрерывного предсказания.

**Текущая физика:** v3

**Референс:** программный runtime на C и формат личности `.d8p`

DECIMA-8 принимает поток восьмиуровневых линий VSB и одновременно предъявляет каждый кадр всем активным тайлам. Тайл взвешивает общий вход, накапливает signed-состояние, теряет его через decay и фиксирует событие, когда аккумулятор входит в заданный коридор.

Соседние тайлы не передают друг другу данные. Локальная топология передаёт только **разрешение вычисляться на следующем такте**. Поэтому ветвь личности является не каналом данных, а последовательностью условий над одной общей историей.

## Физика одного такта

```text
8-lane VSB frame
  -> общий вход всех ACTIVE-тайлов
  -> W[8x8] + signed accumulator + decay
  -> fuse в коридоре [thr_lo..thr_hi]
  -> FIRE при переходе unlocked -> locked
  -> локальное разрешение потомкам
  -> BUS_W readout и доменные события
```

Память возникает в `thr_cur`, `locked` и фронте активированной топологии. Она не хранится отдельным массивом истории: личность интегрирует последовательность непосредственно своим состоянием.

## Кто задаёт личность

Архитектор, или пекарь, определяет смысл восьми входных линий, веса, пороги, decay, топологию, домены, приоритеты и правила сброса. Результат выпечки — `.d8p`: исполняемая конфигурация машины, а не программа с ветвлениями.

Среда даёт ленту. Пекарь задаёт пространство возможных реакций. Decima детерминированно проживает ленту внутри этого пространства.

## Реальное применение

[Whaler](https://whaler.rulerom.com/) — первое прикладное семейство Decima-8. Рыночная микроструктура сжимается в восьмилинейную VSB-ленту; редкие события Decima становятся входом для директора риска и торгового контура. Это не HFT-классификатор каждой свечи, а событийный фильтр дисбаланса.
