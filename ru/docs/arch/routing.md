# Граф локального допуска

Топология Decima-8 распространяет не данные, а право вычисляться.

## RoutingFlags16

| Биты | Значение |
| --- | --- |
| `0..7` | Рёбра N, E, S, W, NE, SE, SW, NW |
| `8` | `BUS_R`: seed ACTIVE-графа, несмотря на историческое имя |
| `9` | `BUS_W`: разрешение вклада в readout |
| `10..15` | Reserved |

Если у тайла A установлен локальный флаг направления, существует ребро допуска `A -> B` к соответствующему соседу.

## Условие активации

```text
ACTIVE[t] =
  BUS_R[t]
  OR exists parent p:
       ACTIVE[p] AND locked_before[p] AND edge(p, t)
```

Рёбра:

- не несут VSB;
- не складывают выход одного тайла во вход другого;
- могут иметь несколько родителей;
- могут образовывать циклы;
- вычисляются детерминированно по снимку `locked_before`.

## Последовательность во времени

```text
Такт N:
  корневой тайл слышит общий VSB и входит в lock

Такт N+1:
  корень уже locked_before
  его потомок получает ACTIVE
  потомок слышит новый общий VSB своим набором весов
```

Так ветвь распознаёт не пакет, путешествующий по ткани, а последовательность состояний общей среды.

## Схлоп ветви

Если предок разблокирован, его потомки теряют разрешение, если у них нет другого locked-пути или собственного `BUS_R`. Неактивная часть ткани сбрасывает runtime-состояние. Это делает топологию одновременно памятью порядка и механизмом забывания.

## Зачем пекарю топология

Пекарь размещает условия так, чтобы:

- корни слушали базовые признаки;
- последующие тайлы проверяли развитие события;
- несколько ветвей могли сойтись в одном домене;
- победитель выдавал pattern id и при необходимости очищал использованную память.

Топология задаёт грамматику реакции, но все её узлы читают одну общую VSB-ленту.
